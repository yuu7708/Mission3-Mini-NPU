# Mini NPU Simulator

## 1. 프로젝트 소개

Python으로 AI의 MAC(Multiply-Accumulate) 연산 방식을 구현한 Mini NPU 시뮬레이터입니다.

입력 패턴에 두 종류의 필터(Cross, X)를 적용하고, MAC 연산 점수를 비교하여 입력 패턴을 판정합니다.

사용자 입력 모드와 JSON 데이터 분석 모드를 제공하며, 다양한 배열 크기에 대한 연산 성능도 측정합니다.

## 2. 실행 환경

- Python 3.8 이상
- Python 표준 라이브러리만 사용
- 사용 모듈: `json`, `time`, `math`, `re`
- NumPy, pandas 등 외부 라이브러리 미사용

## 3. 주요 기능

1. 사용자 입력 모드에서 3×3 필터 A와 B 입력
2. 입력한 필터 확인 및 재입력
3. 3×3 패턴 입력 및 MAC 점수 계산
4. Cross, X, UNDECIDED 판정
5. JSON 파일을 이용한 여러 크기의 패턴 자동 분석
6. JSON 데이터의 배열 크기 및 숫자 형식 검증
7. 필터 이름과 정답 라벨 정규화
8. 잘못된 데이터 및 지원하지 않는 배열 크기 검증
9. 테스트별 PASS 및 FAIL 결과 출력
10. 전체 테스트 결과와 실패 원인 출력
11. 3×3, 5×5, 13×13, 25×25 성능 측정
12. MAC 연산 평균 실행 시간 및 연산 횟수 출력

## 4. MAC 연산 방식

MAC(Multiply-Accumulate)은 같은 위치에 있는 패턴과 필터의 값을 곱한 뒤 모든 결과를 누적하는 연산입니다.

각 위치의 곱셈 결과를 `total` 변수에 더하고, 최종 합계를 연산 점수로 사용합니다.

연산은 중첩 반복문으로 직접 구현했으며, 최종 결과는 실수형(float)으로 반환합니다.

## 5. 판정 방식

Cross 필터 점수와 X 필터 점수를 비교합니다.

- Cross 점수가 더 크면 Cross
- X 점수가 더 크면 X
- 두 점수의 차이가 epsilon(1e-9)보다 작으면 UNDECIDED

동점인 경우 어느 쪽도 선택하지 않도록 처리합니다.

JSON 데이터의 정답 라벨은 다음과 같이 정규화합니다.

- `+` → `Cross`
- `x` → `X`
- `cross` → `Cross`

## 6. 데이터 검증

JSON 분석 과정에서 다음 항목을 검증합니다.

- JSON 파일의 존재 여부 및 문법
- 필터와 패턴 데이터의 구조
- 패턴 이름 형식
- 지원하는 배열 크기(5, 13, 25)
- 패턴과 필터의 행 및 열 개수
- 숫자 형식과 유효한 숫자 여부
- Cross 및 X 필터의 존재 여부
- 필터 이름의 중복 여부

잘못된 데이터가 발견되면 해당 테스트 케이스를 FAIL로 처리하고 실패 원인을 출력합니다.

사용자 입력 모드에서도 숫자가 아닌 값이나 잘못된 행의 숫자 개수를 검사하고 재입력을 요청합니다.

## 7. 테스트 결과 리포트

JSON 데이터의 총 6개 테스트 케이스를 실행했습니다.

| 테스트 케이스 | Cross 점수 | X 점수 | 판정 | 결과 |
|---|---:|---:|---|---|
| size_5_1 | 0.9 | 0.9 | UNDECIDED | FAIL |
| size_5_2 | 8.9 | 0.1 | Cross | PASS |
| size_13_1 | 0.3 | 14.7 | X | PASS |
| size_13_2 | 7.5 | 7.5 | UNDECIDED | FAIL |
| size_25_1 | 4.9 | 4.9 | UNDECIDED | FAIL |
| size_25_2 | 52.9 | 0.1 | Cross | PASS |

- 전체 테스트: 6개
- PASS: 3개
- FAIL: 3개

## 8. 실패 원인 분석

실패한 세 케이스는 프로그램 오류가 아니라 두 필터의 MAC 점수가 동일하게 나온 경우입니다.

- size_5_1: Cross 0.9, X 0.9
- size_13_2: Cross 7.5, X 7.5
- size_25_1: Cross 4.9, X 4.9

현재 판정 규칙은 두 점수의 차이가 epsilon(1e-9)보다 작으면 UNDECIDED를 반환합니다.

따라서 정답이 Cross 또는 X로 지정되어 있어도 두 점수가 같으면 정답을 확정할 수 없어 FAIL로 처리됩니다.

이 결과는 epsilon을 이용한 동점 판정이 정상적으로 동작하고 있음을 보여줍니다.

FAIL을 임의로 PASS로 변경하지 않고 실제 연산 결과와 판정 규칙을 그대로 유지했습니다.

## 9. 성능 측정 결과

각 배열 크기의 MAC 연산을 1,000회 반복하고 평균 실행 시간을 측정했습니다.

| 배열 크기 | 평균 시간(ms) | 연산 횟수 |
|---|---:|---:|
| 3×3 | 0.001693 | 9 |
| 5×5 | 0.002676 | 25 |
| 13×13 | 0.010300 | 169 |
| 25×25 | 0.034314 | 625 |

측정 시간은 컴퓨터 환경 및 실행 상황에 따라 달라질 수 있습니다.

성능 측정에서는 입력 및 출력 시간을 제외하고 MAC 연산 시간만 측정합니다.

## 10. 시간 복잡도 분석

MAC 연산은 배열의 모든 행과 열을 한 번씩 반복합니다.

N×N 배열에서는 총 N²번의 곱셈과 누적 연산이 발생합니다.

따라서 시간 복잡도는 O(N²)입니다.

배열 크기가 증가하면 연산 횟수도 제곱에 비례하여 증가합니다.
