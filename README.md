\# Mini NPU Simulator



\## 1. 프로젝트 소개



Python으로 AI의 MAC(Multiply-Accumulate) 연산 방식을 흉내 내는 작은 계산기입니다.



두 종류의 필터(Cross, X)에 입력 패턴을 적용하고, 연산 점수를 비교하여 패턴을 판정합니다.



\## 2. 실행 환경



\- Python 3.8 이상

\- 표준 라이브러리만 사용

\- 사용 모듈: json, time, math, re

\- 외부 라이브러리 및 NumPy 미사용



\## 3. 주요 기능



1\. 사용자 입력 모드에서 3×3 필터 A와 B 입력

2\. 입력한 필터 확인 및 재입력

3\. 3×3 패턴 입력 및 MAC 점수 계산

4\. 두 점수를 비교하여 Cross, X, UNDECIDED 판정

5\. data.json 파일을 읽어 여러 크기의 패턴 자동 분석

6\. JSON 데이터의 배열 크기와 숫자 형식 검증

7\. 정답 라벨을 Cross와 X로 통일

8\. 테스트별 PASS 및 FAIL 결과 출력

9\. 전체 테스트 결과와 실패 원인 출력

10\. 3×3, 5×5, 13×13, 25×25 성능 측정



\## 4. MAC 연산 방식



MAC 연산은 같은 위치에 있는 패턴과 필터의 값을 곱한 뒤 모든 결과를 누적하는 방식입니다.



각 위치의 곱셈 결과를 total에 더하며, 최종 합계를 연산 점수로 사용합니다.



\## 5. 판정 방식



Cross 필터 점수와 X 필터 점수를 비교합니다.



\- Cross 점수가 더 크면 Cross

\- X 점수가 더 크면 X

\- 두 점수의 차이가 1e-9보다 작으면 UNDECIDED



동점인 경우에는 어느 쪽도 선택하지 않습니다.



\## 6. 테스트 결과 리포트



JSON 데이터의 총 6개 테스트 케이스를 실행했습니다.



\- 전체 테스트: 6개

\- PASS: 3개

\- FAIL: 3개



PASS 케이스:

\- size\_5\_2

\- size\_13\_1

\- size\_25\_2



FAIL 케이스:

\- size\_5\_1

\- size\_13\_2

\- size\_25\_1



\## 7. 실패 원인 분석



실패한 세 케이스는 프로그램 오류가 아니라 두 필터의 MAC 점수가 동일하게 나온 경우입니다.



\- size\_5\_1: Cross 0.9, X 0.9

\- size\_13\_2: Cross 7.5, X 7.5

\- size\_25\_1: Cross 4.9, X 4.9



현재 판정 규칙은 두 점수의 차이가 epsilon(1e-9)보다 작으면 UNDECIDED를 반환합니다.



따라서 정답이 Cross 또는 X로 지정되어 있어도 두 점수가 같으면 정답을 확정할 수 없어 FAIL로 처리됩니다.



이 결과는 epsilon을 이용한 동점 판정이 정상적으로 동작하고 있음을 보여줍니다.



\## 8. 성능 측정 결과



각 크기의 MAC 연산을 1000회 반복하고 평균 실행 시간을 측정했습니다.



| 배열 크기 | 평균 시간(ms) | 연산 횟수 |
|---|---:|---:|
| 3×3 | 0.001669 | 9 |
| 5×5 | 0.002658 | 25 |
| 13×13 | 0.010281 | 169 |
| 25×25 | 0.033877 | 625 |



측정 시간은 실행 환경에 따라 달라질 수 있습니다.



\## 9. 시간 복잡도 분석



MAC 연산은 배열의 모든 행과 열을 한 번씩 반복합니다.



N×N 배열에서는 총 N²번의 곱셈과 누적 연산이 발생합니다.



따라서 시간 복잡도는 O(N²)입니다.



배열 크기가 커질수록 연산 횟수도 제곱에 비례하여 증가합니다.



\## 10. 실행 방법



프로젝트 폴더에서 다음 명령어를 실행합니다.



```bash

python main.py

```



JSON 분석 모드를 사용하려면 main.py와 data.json 파일이 같은 폴더에 있어야 합니다.
